GUIA DO SISTEMA ACERVO

Criar uma caixa nova admin
Para criar uma caixa nova, entre na estante onde deseja colocá-la e clique no botão "+ Nova caixa" no canto superior. Digite o código oficial da caixa (ex: A1-020 ou NSF D1-005) e uma descrição rápida do conteúdo. Caixas são ordenadas de forma natural pelo código alfanumérico.
Adicionar pessoa ou documento
Entre na caixa correspondente. No topo haverá o formulário com o seletor Pessoa | Documento. Para Pessoa, preencha o Nome Completo e o Cargo. Para Documento, preencha o Título, o Tipo (Contrato, Processo, Nota fiscal ou Outro), Data e local físico de guarda. Ambos contam com campo de Observação adicional.
Mover ou apagar uma caixa admin
Na visualização interna da caixa, administradores têm acesso aos botões "Mover caixa" (para trocar a mobília/estante de destino) e "Excluir caixa". Ao apagar, a caixa é movida para a Lixeira com estado excluido: true, podendo ser restaurada a qualquer instante.
Adicionar um colaborador admin
Clique no botão "Colaboradores" no cabeçalho do setor. Você poderá convidar novos usuários informando o endereço de e-mail e os nomes dos setores liberados separados por vírgula. É possível também torná-lo administrador definindo os setores no campo específico.
Resolver um conflito de edição
Quando dois usuários abrem e editam o mesmo registro simultaneamente, o sistema compara a marca temporal de ultimaAlteracao. Caso o documento tenha sido modificado no servidor antes de você salvar, o painel amarelo de conflito será exibido oferecendo "Ver a versão mais recente" ou "Manter minha versão" com sobrescrita explícita.
